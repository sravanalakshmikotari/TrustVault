# TrustVault

TrustVault is a secure document management system designed to store, manage, and share documents safely.

## Features
- Secure User Login
- Document Upload
- Document Management
- Access Control
- Document Sharing
- Activity Tracking

## Technology Stack
- Python
- Flask
- HTML
- CSS
- SQLite

## Project Objective
To provide a simple and secure platform for managing and sharing documents with controlled access.
